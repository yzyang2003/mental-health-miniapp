## 任务：预测房价

给定房屋面积，预测价格。这是最简单的**回归问题**。

---

## 完整代码（带逐行注释）

```python
import torch
import torch.nn as nn
import torch.optim as optim

# ============================================
# 第 1 步：准备数据
# ============================================

# 训练数据：房屋面积（平方米）→ 价格（万元）
# 60㎡ → 150万，80㎡ → 200万，100㎡ → 250万，120㎡ → 300万
areas = torch.tensor([[60], [80], [100], [120]], dtype=torch.float32)
prices = torch.tensor([[150], [200], [250], [300]], dtype=torch.float32)

# 为什么要是 tensor？因为 PyTorch 只认识 tensor 格式
# dtype=torch.float32 表示用浮点数（小数）

# ============================================
# 第 2 步：定义模型
# ============================================

# 这个问题很简单：价格 = 面积 × 某个系数 + 偏置
# 所以只需要一层线性回归
model = nn.Linear(in_features=1, out_features=1)

# nn.Linear(1, 1) 是什么意思？
# - in_features=1：输入是 1 个数字（面积）
# - out_features=1：输出是 1 个数字（价格）
# - 内部自动创建了两个参数：权重 w 和偏置 b
# - 初始值是随机的，所以一开始猜得很离谱

print("模型初始参数：")
print(f"  权重 w = {model.weight.item():.4f}")
print(f"  偏置 b = {model.bias.item():.4f}")

# ============================================
# 第 3 步：定义损失函数和优化器
# ============================================

# 损失函数：均方误差（MSE）
# 预测值和真实值的差的平方，再取平均
criterion = nn.MSELoss()

# 优化器：随机梯度下降（SGD）
# 根据损失函数算出的梯度，更新模型参数
# lr=0.001 是学习率，每次走多大一步
optimizer = optim.SGD(model.parameters(), lr=0.001)

# ============================================
# 第 4 步：训练模型
# ============================================

print("\n开始训练...")
for epoch in range(1000):  # 重复 1000 次
    # --- 前向传播 ---
    predictions = model(areas)  # 把数据喂给模型，得到预测值
    loss = criterion(predictions, prices)  # 算损失：猜得有多差
    
    # --- 反向传播 ---
    optimizer.zero_grad()  # 清空之前的梯度（重要！）
    loss.backward()        # 计算梯度（每个参数该调多少）
    optimizer.step()       # 更新参数（根据梯度调整）
    
    # 每 200 轮打印一次
    if (epoch + 1) % 200 == 0:
        w = model.weight.item()
        b = model.bias.item()
        print(f"  Epoch {epoch+1:4d} | 损失: {loss.item():.4f} | w: {w:.4f} | b: {b:.4f}")

# ============================================
# 第 5 步：用训练好的模型预测
# ============================================

print("\n训练完成！")
print(f"最终参数：w = {model.weight.item():.4f}, b = {model.bias.item():.4f}")

# 预测：90㎡ 的房子值多少钱？
test_area = torch.tensor([[90]])
predicted_price = model(test_area)
print(f"\n预测：90㎡ 的房子值 {predicted_price.item():.0f} 万")

# 真实答案应该是 225万（线性插值）
# 如果预测接近 225，说明模型学到了规律
```

## 代码和概念的对应关系

| 代码 | 对应概念 | 生活类比 |
|------|---------|---------|
| `model = nn.Linear(1, 1)` | 初始化模型 | 小孩一开始啥都不懂 |
| `predictions = model(areas)` | 前向传播 | 小孩猜水果 |
| `loss = criterion(predictions, prices)` | 损失函数 | 大人告诉他猜错了 |
| `loss.backward()` | 反向传播 | 小孩想想哪里猜错了 |
| `optimizer.step()` | 梯度下降 | 小孩调整判断标准 |
| `for epoch in range(1000)` | 训练循环 | 反复练习很多次 |

## 关键细节解释

### 为什么 optimizer.zero_grad()？
```python
# PyTorch 默认会累加梯度
# 如果不清空，每次的梯度会叠加，导致更新方向错误
# 所以每次训练前要清空
optimizer.zero_grad()
```

### 为什么损失在减小？
```
初始：w=0.23, b=-0.12 → 预测值和真实值差很远 → 损失大
最终：w=2.50, b=0.57 → 预测值和真实值很接近 → 损失小
```
模型通过不断调整 w 和 b，让预测越来越准。

### 这个模型学到了什么？
```
价格 ≈ 面积 × 2.5 + 0.57
```
真实世界的房价大约是：每平米 2.5 万 + 基础价 0.57 万
模型自己从数据中发现了这个规律！
