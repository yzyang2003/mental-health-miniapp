# Day 1：机器学习是什么

> 目标：理解机器学习的核心概念，知道"训练"是怎么回事

---

## 一、传统编程 vs 机器学习

### 传统编程
```
人写规则 → 机器执行
```
例子：判断邮件是否是垃圾邮件
- 人写规则：如果包含"中奖"、"免费" → 垃圾邮件
- 机器按规则执行

**问题**：规则太复杂写不完，而且会变化

### 机器学习
```
人给数据 → 机器自己学规则
```
例子：判断邮件是否是垃圾邮件
- 人给 10000 封已标注的邮件（垃圾/正常）
- 机器自己找规律

**核心思想**：让机器从数据中"发现"规则，而不是人硬写

## 二、监督学习（最常用）

### 什么是监督学习？
给模型一堆"带答案的题目"让它学：

| 输入（特征） | 输出（标签） |
|-------------|-------------|
| 邮件内容："恭喜你中奖100万" | 垃圾邮件 |
| 邮件内容："明天开会别忘了" | 正常邮件 |
| 房屋面积：80㎡，2室1厅 | 价格：150万 |
| 房屋面积：120㎡，3室2厅 | 价格：280万 |

### 两类问题

**1. 分类问题** — 答案是"类别"
- 垃圾邮件 vs 正常邮件
- 猫 vs 狗
- 疾病阳性 vs 阴性

**2. 回归问题** — 答案是"数字"
- 房价预测
- 温度预测
- 股票价格预测

## 三、模型训练的完整过程

用一个生活例子来理解：**教小孩认水果**

### 第 1 步：准备数据
```
苹果 → 红色、圆形、甜 → 苹果
香蕉 → 黄色、长条、甜 → 香蕉
橘子 → 橙色、圆形、酸 → 橘子
```
这就是**训练数据**：输入（颜色、形状、味道）+ 输出（水果名）

### 第 2 步：模型"猜"一次
小孩第一次见到水果，瞎猜：
```
输入：红色、圆形、甜
小孩猜：这是...橘子？（错了）
```
这就是**前向传播**：输入 → 模型 → 输出预测值

### 第 3 步：告诉小孩答案
```
大人说：不对，这是苹果！
小孩知道：我猜错了，差了多远？
```
这就是**损失函数**：计算预测值和真实值的差距

### 第 4 步：小孩调整"判断标准"
```
小孩想：红色+圆形=苹果，我之前记错了
下次见到红色圆形的，我要更倾向猜苹果
```
这就是**反向传播 + 梯度下降**：根据误差调整模型参数

### 第 5 步：重复很多次
```
看了 1000 个水果后，小孩终于学会了
```
这就是**训练**：重复以上步骤，直到模型表现够好

## 四、关键概念速查

### 损失函数（Loss Function）
- 衡量"猜得有多差"
- 值越大 = 猜得越离谱
- 训练目标：让损失函数的值尽可能小

### 梯度下降（Gradient Descent）
- 找到"下坡最快的方向"来调整参数
- 像蒙着眼下山，每次摸一下脚边的坡度，往低处走一步

### 学习率（Learning Rate）
- 每次走多大一步
- 太大：步子扯着蛋，走过了
- 太小：走太慢，训练到天荒地老
- 一般取 0.001、0.01 这种小数

### Epoch（轮次）
- 把所有训练数据看一遍 = 1 个 epoch
- 通常要看好几遍才能学会

### Batch Size（批大小）
- 一次看多少条数据
- 太大：显存不够
- 太小：学习不稳定
- 常见值：32、64、128

### 过拟合 vs 欠拟合
```
过拟合：死记硬背，只认训练过的题，新题不会做
欠拟合：根本没学会，连训练题都做不对
```

### 训练集 / 验证集 / 测试集
```
训练集（70%）：给模型学的题
验证集（15%）：学的过程中考一考，防止学歪
测试集（15%）：最后期末考试，完全没见过的题
```

## 五、一张图总结

```
输入数据
    ↓
┌─────────┐
│  模型    │ ← 参数（权重和偏置）
│ (Model) │
└─────────┘
    ↓
预测值
    ↓
损失函数 ← 对比真实值
    ↓
反向传播 → 计算梯度
    ↓
梯度下降 → 更新参数
    ↓
重复 N 次（Epoch）
    ↓
训练完成！
```
